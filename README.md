# Azzurro Hotels — Modern Applicant Journey

Modern GitHub Pages-ready recruitment prototype for the Housekeeping Attendant role.

## Pages
- `index.html` — public job posting + application journey + 5-question video interview + thank-you screen
- `admin.html` — admin recruitment dashboard preview

## Current mode
This is intentionally a visual/UX prototype. No applicant data or video is sent to a backend yet.

## Later Supabase integration
When credentials are provided, connect:
- applicant details
- eligibility responses
- resume upload
- 5 interview video uploads
- interview completion state
- application statuses
- admin authentication
- notes / decisions
- Supabase Row Level Security

## GitHub Pages
Upload the files to the root of your repository and enable GitHub Pages in repository settings.
